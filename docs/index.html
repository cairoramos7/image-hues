Extraia as cores dominantes de qualquer imagem

Biblioteca TypeScript leve que analisa uma imagem via Canvas API e retorna as cores dominantes e suas cores de contraste — sem enviar nada a um servidor. Teste abaixo.

Como funciona

01

Carrega a imagem

A imagem é lida localmente e desenhada em um <canvas> oculto no navegador.

02

Amostra os pixels

Os pixels são amostrados e agrupados por cor para encontrar as tonalidades mais frequentes.

03

Calcula o contraste

Para cada cor dominante, calcula-se a luminância e retorna preto ou branco como contraste ideal.

Nenhuma imagem sai do seu navegador — todo o processamento acontece localmente via Canvas API.
